# Reference

file owns one subject; this index is the entry point. Feature walkthroughs
live in [documentation/features/](../features/), domain procedures in
`.skills/`, and the operator-facing variable reference is generated from
`src/config/spec.ts`.

House rules for this directory:

- One subject per file; when a file grows past a single subject, split it and
  add the new file here.
- `configuration.md` is generated by `scripts/tools/generate-config.ts` —
  change `src/config/spec.ts`, then regenerate.
- Descriptions state durable rules, not current counts; measured snapshots
  carry their measurement date and a reproduce path.
- `history/` holds dated incident records — historical notes, not evidence of
  current behavior.
